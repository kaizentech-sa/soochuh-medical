# Soochuh Medical CMS Access

## Entering Sanity Studio Backend

This project has Sanity Studio embedded at:

- [http://localhost:3000/studio](http://localhost:3000/studio)

### Steps

1. Start the app in dev mode.
2. Open `/studio` in your browser.
3. Sign in with your Sanity account.
4. Select the correct project/dataset when prompted.
5. You are now inside the CMS backend.

## What You Should See

After login, the Studio sidebar should show singleton content sections:

- Hero
- About
- Services
- Testimonials
- Contact
- Bookings
- Site Theme

## Notes

- Studio access is role-based in Sanity. If you cannot edit content, your account likely needs project permissions.
- Use `/studio` for content management only; the main website remains at `/`.
